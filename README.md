# カギヤ 口コミ下書き（EC・イベント）

カギヤブルワリーのお客さまが、飲んだ感想のアンケートに答えると、答えだけから商品レビューの下書きができるページです。投稿はお客さま本人が、カラーミーショップのレビュー画面で行います。

- 答えは「カギヤ 口コミのカギ」（店舗のGoogle口コミのお手伝いページ）と同じ保存先に、名前・連絡先なしで記録します（区分：醸造部）。
- お店への意見は、口コミの下書きには入りません。
- QR：`?src=ec&p=商品番号`（ECの同梱カード）／`?src=line&p=商品番号`／`?src=event`（イベントは共通のQR。イベント名はお客さまが書く）
